
### ROS

로봇 소프트웨어의 미들웨어이자 생태계입니다. "운영체제"라는 이름과 달리 리눅스 위에서 도는 프레임워크로, 노드들을 느슨하게 연결하고 메시지를 주고받게 해 줍니다.


- robot operating System
	- 라이브러리
		- TF2
		- 로봇의 부품, 센서, 그리고 주변 환경 간의 **3차원 좌표계(Transform Frame) 위치와 회전 관계를 시간에 따라 추적하고 변환**해 주는 핵심 라이브러리
		- 로봇의 중심(`base_link`)과 카메라 센서(`camera_link`) 사이의 거리를 계산하거나, 지도(`map`) 좌표계에서 로봇의 위치를 파악할 때 사용됩니다
	- ![[Pasted image 20260811095006.png]]
	- DDS
- topic 을 event,subscription 할떄 표시를 /를 붙여서 사용
	- **/image, /scan**
	- ROS2에서 노드들이 서로를 직접 호출하지 않고 메시지를 주고받기 위해 사용하는, 이름이 붙은 단방향 메시지 흐름

- callback (콜백)
	- 구독, 서비스, 타이머
	- 어떤 일이 생기면 이 함수를 불러라'라고 미리 사전 정의 해 두는, 이벤트 발생 시 실행되는 함수

기본적으로 ROS는 비동기적 구조 (이벤트 발행 - 구독)
- flutter에서 작업했던, 이벤트 버스 구조(event bus pattern)과 비슷하게 이해된다
- 콜백의 개념 역시, Javascript 등 다른 프로그래밍에서 사용되는 함수와 같은 역할로 이해

용어사전 

**MPPI (Model Predictive Path Integral)**

MPPI는 모델 예측 제어(MPC)와 확률적 샘플링 기법을 결합한 최신 로컬 플래너 알고리즘입니다. GPU 또는 멀티코어 CPU 기반의 수천 개 샘플링을 활용해 최적의 제어 명령을 계산합니다.

- **동작 방식:**
    
    1. 로봇의 키네마틱/동역학 모델을 기반으로 무작위 노이즈를 섞은 수천 개의 제어 입력을 동시에 생성합니다.
        
    2. 각 궤적에 대한 비용(Cost)을 평가합니다(경로 이탈, 장애물 침범, 속도 급변 제약 등).
        
    3. Softmax 형태의 가중 평균을 적용하여 가장 비용이 적게 드는 궤적 방향으로 제어 노이즈를 업데이트하고 최적 제어값을 결정합니다.
        
- **장점:**
    
    - 비선형 모델 및 차동/아커만/옴니식 등 다양한 동역학 구조를 손쉽게 반영할 수 있습니다.
        
    - 복잡하거나 좁은 공간에서도 매끄럽고 안정적인 우회 경로를 생성합니다.
        
    - 장애물 회피 성능과 실시간 경로 수정 능력이 매우 뛰어납니다.
        
- **단점:** 수많은 샘플링 궤적을 실시간으로 연산해야 하므로 DWA에 비해 높은 컴퓨팅 자원(GPU 추천 또는 높은 CPU 성능)을 요구합니다.

---
**DWA (Dynamic Window Approach)**

DWA는 속도 공간(Velocity Space)에서 로봇의 물리적 제약(최대 속도, 가속도 한계) 내에서 도달 가능한 속도 조합 $(v, \omega)$ 영역을 정의한 뒤, 그 안에서 최적의 경로를 선별하는 탐색 알고리즘입니다.

- **동작 방식:**
    
    1. 현재 속도와 가속도 제한을 고려해 다음 제어 주기 동안 로봇이 도달 가능한 속도 범위를 설정합니다(Dynamic Window).
        
    2. 범위 내 속도 조합들을 샘플링하여 미래의 궤적(주로 호 형태)을 예측합니다.
        
    3. 평가 함수(장애물과의 거리, 목표 지점과의 거리, 글로벌 경로와의 일치도 등)를 통해 각 궤적에 점수를 매겨 가장 점수가 높은 속도를 최종 출력합니다.
        
- **장점:** 계산량이 적고 구조가 직관적이어서 CPU 자원이 부족한 임베디드 시스템이나 차동 구동(Differential Drive) 로봇에 적합합니다.
    
- **단점:** 단순한 선형/회전 속도 보간 기반이라 장애물이 복잡하거나 좁은 공간에서 갇히기 쉬우며, 로봇의 복잡한 동역학 모델을 반영하기 어렵습니다.

---
DWA, MPPI 비교 

|**구분**|**DWA (Dynamic Window Approach)**|**MPPI (Model Predictive Path Integral)**|
|---|---|---|
|**주요 접근법**|속도 공간 샘플링 및 평가|모델 예측 + 확률적 대규모 샘플링|
|**연산량 / 자원**|매우 낮음 (저성능 CPU 가능)|높음 (GPU 또는 고성능 CPU 권장)|
|**주요 로봇 타입**|차동 구동, 옴니식 로봇|차동, 옴니, 아커만 조향(자동차 형태) 등 전체|
|**장애물 회피 능력**|단순 장애물 환경에 적합|복잡하고 협소한 환경에서 뛰어남|
|**궤적의 부드러움**|각진 이동이나 진동 발생 가능|매우 매끄럽고 자연스러운 이동|
