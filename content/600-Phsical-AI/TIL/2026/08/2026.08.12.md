DDS (Data Distribution Service) 란?

DDS는 객체 관리 그룹([OMG](https://www.omg.org/))에서 표준화한 **데이터 중심(Data-Centric)의 발행/구독(Publish/Subscribe) 미들웨어 표준**입니다.

- **데이터 중심(Data-Centric)**: 서버가 어디에 있는지, 주소가 무엇인지 몰라도 됩니다. 오직 **"내가 원하는 데이터의 이름(Topic)"**만 알면 시스템이 알아서 데이터를 찾아 연결해 줍니다.
- **발행/구독(Pub/Sub) 모델**: 데이터를 보내는 자(Publisher)와 받는 자(Subscriber)가 서로의 존재를 직접 몰라도 통신할 수 있어, 시스템 구조가 매우 유연해집니다.
- **브로커리스(Broker-less) 구조**: 중간에서 중재하는 중앙 서버(브로커)가 없습니다. 단말기끼리 p2p(Peer-to-Peer) 형태로 직접 통신하기 때문에 **초고속, 저지연(Low-Latency)** 통신이 가능하며 중앙 서버 장애로 전체 시스템이 멈추는 일이 없습니다.
- **주요 사용처**: 군사/방산 시스템, 자율주행 자동차(ROS2 아키텍처의 기반), 스마트 팩토리, 전력망 제어 등.

2. QoS (Quality of Service) 란?

DDS 환경에서 QoS는 **"데이터를 어떻게 주고받을 것인가?"에 대한 계약 조건**입니다.

중앙 서버가 없는 DDS 특성상, 데이터를 보낼 때 "신뢰성을 높일지", "속도를 높일지", "과거 데이터를 보관할지" 등을 **QoS 정책을 통해 세밀하게 설정**해야 합니다. DDS는 수십 가지의 강력한 QoS 설정을 지원합니다.

DDS의 대표적인 QoS 정책 예시

- **Reliability (신뢰성)**
    - `Reliable`: 데이터가 유실되면 다시 보내서라도 **무조건 100% 전달**합니다. (예: 결제, 제어 명령)
    - `Best Effort`: 네트워크가 바쁘면 유실을 감수하고 **최대한 빠르게만 보냅니다.** (예: 영상 스트리밍, 실시간 센서 값)
- **History (이력 보관)**
    - `Keep Last (N)`: 가장 최근에 들어온 N개의 데이터만 보관합니다.
    - `Keep All`: 메모리가 허용하는 한 모든 과거 데이터를 보관합니다.
- **Durability (지속성)**
    - 데이터를 새로 구독(접속)한 단말기에게, **그 이전에 발행되었던 과거 데이터를 전달할지 말지**를 결정합니다. (예: 새로 켜진 장비가 기존 시스템의 마지막 상태 값을 바로 이어받을 때 사용)
- **Deadline (마감 시간)**
    - "적어도 10ms 안에는 데이터가 들어와야 한다"고 설정하는 것입니다. 만약 이 시간 안에 데이터가 안 오면 시스템에 경고(알람)를 보냅니다. (실시간성 보장)
- **Liveliness (활성 상태)**
- 데이터를 보내는 장치가 여전히 '살아있는지(통신 가능한지)' 주기적으로 체크합니다.

#### 정의된  QoS profile


| 프로파일            | 구성                                 | 용도            |
| --------------- | ---------------------------------- | ------------- |
| **Default**     | Reliable, Volatile, KeepLast(10)   | 일반 통신(명령 등)   |
| **Sensor Data** | Best-Effort, Volatile, KeepLast(5) | 카메라·LiDAR 스트림 |
| **Services**    | Reliable                           | 서비스 통신        |
| **Parameters**  | Reliable                           | 파라미터          |


``` python
from rclpy.qos import qos_profile_sensor_data

# 센서 데이터엔 전용 프로파일
self.sub = self.create_subscription(
    LaserScan, '/scan', self.on_scan, qos_profile_sensor_data)
```
